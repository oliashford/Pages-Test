## Formatting

### Text Styling

- **Bold text** using `**` or `__`
- *Italic text* using `*` or `_`
- ~~Strikethrough~~ using `~~`

You can also include inline code, for example: `inline code`.

### Headings

Markdown supports headings from `#` (largest) to `######` (smallest).
